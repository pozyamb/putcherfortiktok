putcherfortiktok 0.1.0
======================

Локальная подготовка видео к загрузке в TikTok на видеокартах NVIDIA RTX.
Работает без интернета, файлы никуда не отправляются.

Запуск
------
1. Распакуйте архив целиком в любую папку. Путь к папке лучше без кириллицы.
2. Запустите putcherfortiktok.exe.
   Файлы ffmpeg.exe, ffprobe.exe, WebView2Loader.dll и папка rife должны
   оставаться рядом с программой.

Требования
----------
- Windows 10 или 11, 64-бит
- WebView2 Runtime (в Windows 11 уже есть; для Windows 10 его можно
  скачать у Microsoft)
- Видеокарта NVIDIA с NVENC и свежий драйвер. Без неё работает только
  патч, без улучшения видео.

Как пользоваться
----------------
1. Перетащите один или несколько роликов в окно.
2. Справа выберите пресет или настройте шаги вручную:
   Шаг 1 "Видео": апскейл, частота кадров, шумоподавление, резкость.
   Шаг 2 "Патч": применяется последним, к готовому файлу.
3. Нажмите "Оптимизировать". Результат появится рядом с исходником
   как <имя>_tiktok.mp4.
4. Загружайте файл в TikTok как есть, ничего не редактируя в самом TikTok.

Достройка кадров нейросетью RIFE временно сохраняет все кадры на диск
рядом с роликом: на минуту видео 1080p нужно около 12 ГБ свободного места.
Размытие движения тоже работает через RIFE и занимает долго: на RTX 5060
около 10 минут на минуту видео 1080p при высокой плавности.

Сторонние компоненты
--------------------
- FFmpeg (ffmpeg.exe, ffprobe.exe): сборка BtbN "win64-gpl", лицензия
  GNU GPL версии 3. Исходный код: https://github.com/FFmpeg/FFmpeg
  Сборочные скрипты: https://github.com/BtbN/FFmpeg-Builds
- rife-ncnn-vulkan (папка rife): лицензия MIT, см. rife\LICENSE.
  https://github.com/nihui/rife-ncnn-vulkan
- WebView2Loader.dll: Microsoft, распространяется вместе с WebView2 SDK.

Исходный код программы: https://github.com/pozyamb/putcherfortiktok

Программа не связана с TikTok и NVIDIA.
