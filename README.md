# putcherfortiktok

Локальное десктоп-приложение, которое готовит видео к загрузке в TikTok так, чтобы платформа пережимала его как можно мягче. Обработка идёт на видеокартах NVIDIA RTX через NVENC, без облака и без сети: приложение не делает сетевых запросов, ffmpeg поставляется вместе с ним.

Подробный план и макет интерфейса: [docs/plan.html](docs/plan.html).

## Порядок обработки

1. **Видео** (по желанию) — улучшение и кодирование на видеокарте.
2. **Ремукс** — перепаковка без перекодирования.
3. **Патч** — правки в готовом файле. Патч всегда идёт последним.

## Шаг 1: улучшение

Масштабирование до 1080p / 1440p / 4K (три алгоритма), шумоподавление, резкость, удаление полос на градиентах, 60 или 120 fps (смешивание кадров на GPU или интерполяция по движению на CPU), кодек H.264 или HEVC, битрейт. Масштабирование идёт в libplacebo (Vulkan), кодирование — NVENC (`preset p7`, VBR). На выходе всегда 8-bit BT.709.

RTX Video SDK (Super Resolution от NVIDIA) пока не подключён: SDK нужно отдельно скачать у NVIDIA и вшить в сборку.

## Шаг 2–3: ремукс и патч

- **Патч хвоста аудио** — как у сайта-образца на ноябрь 2026: последние 4 аудиокадра перезаписываются на месте фиксированной вставкой, видео не меняется. На контрольном ролике результат совпал с образцом байт в байт, кроме строки с версией ffmpeg.
- **Ремукс** — без перекодирования: moov в начало файла, цветовые теги BT.709, очистка метаданных.
- **Ретайминг (эксперимент)** — надстройка над ремуксом: временные метки видео растягиваются в N раз (`-itsscale N`), файл объявляет частоту кадров в N раз ниже, а в заголовок пишется метка скорости ×N (`mvhd rate` или `elst media rate`). Кадры не меняются. На компьютере такой файл играет замедленно. Работает ли это в TikTok, не проверено — нужен A/B-тест.
## Стек

Tauri 2 (Rust) + React + TypeScript + Vite. ffmpeg/ffprobe с NVENC подключаются как sidecar.

## Требования для разработки (Windows)

- Node.js LTS
- Rust (rustup, toolchain `stable-x86_64-pc-windows-msvc`)
- Компилятор C++, на выбор:
  - Visual Studio Build Tools 2022+ с компонентом «Разработка классических приложений на C++» (toolchain `stable-x86_64-pc-windows-msvc`), или
  - MinGW-w64 (`winget install BrechtSanders.WinLibs.POSIX.MSVCRT`) и toolchain `stable-x86_64-pc-windows-gnu` (`rustup override set stable-x86_64-pc-windows-gnu` в `src-tauri`). В этом варианте путь к проекту должен быть только из латинских символов: инструменты MinGW не открывают файлы по кириллическим путям.
- WebView2 (в Windows 11 уже есть)
- GeForce RTX 20xx или новее, драйвер 551+

## Запуск

```bash
npm install
powershell -ExecutionPolicy Bypass -File scripts/fetch-ffmpeg.ps1
npm run tauri dev
```

Скрипт один раз скачивает ffmpeg и ffprobe с NVENC в `src-tauri/binaries/` (нужен только разработчику, при сборке). Тесты: `cargo test` в `src-tauri`.

Только фронтенд, без Rust:

```bash
npm run dev
```
