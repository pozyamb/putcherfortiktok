# putcherfortiktok

Программа для Windows, которая готовит видео к загрузке в TikTok так, чтобы он не сжимал качество. Работает на видеокартах NVIDIA RTX, полностью на вашем компьютере, без интернета.

## Что умеет

- **Патч** — позволяет выкладывать видео в TikTok без потери качества.
- **Апскейл** до 1080p, 1440p или 4K.
- **Частота кадров 60 и 120 fps** — смешиванием кадров, по движению или нейросетью RIFE.
- **Размытие движения и шлейф** — смазывает движущиеся объекты и повороты камеры, как в эдитах; сила размытия до 500 % и длина затухающего шлейфа до 15 кадров настраиваются отдельно.
- **Шумоподавление, резкость, удаление полос** на градиентах.
- **Очередь** — несколько роликов подряд с одними настройками.
- **Пресеты** — пять готовых наборов настроек и свои.
- **Анализ ролика** — показывает, что в файле может помешать TikTok.

## Основные компоненты

- **putcherfortiktok.exe** — сама программа с интерфейсом.
- **ffmpeg и ffprobe** — анализ и кодирование видео на видеокарте (NVENC).
- **RIFE** — нейросеть для достройки кадров.
- **WebView2** — компонент Windows, на котором работает окно программы.

Всё это уже лежит внутри установщика.

## Как пользоваться

1. Скачайте `putcherfortiktok_0.1.0_x64-setup.exe` со страницы [релизов](https://github.com/pozyamb/putcherfortiktok/releases) и установите.
2. Запустите программу и перетащите в окно один или несколько роликов.
3. Справа выберите пресет или настройте вручную:
   - **Шаг 1 · Видео** — улучшение: разрешение, частота кадров, резкость. Можно оставить «Без изменений».
   - **Шаг 2 · Патч** — применяется последним, к готовому файлу.
4. Нажмите «Оптимизировать». Результат появится рядом с исходником как `имя_tiktok.mp4`.
5. Загрузите этот файл в TikTok как есть, ничего не редактируя в самом TikTok.

Нужны Windows 10 или 11 и видеокарта NVIDIA с NVENC. Без видеокарты NVIDIA работает только патч, без улучшения видео.
