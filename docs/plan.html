Clipforge: локальный оптимизатор видео под TikTok на RTX

Десктоп-приложение, которое готовит ролик к загрузке так, чтобы TikTok пережимал его как можно мягче. Обработка идёт на видеокарте через NVENC, без облака и без очередей. «Clipforge» — рабочее имя, поменяем.

Что мы копируем у референса

Как устроен облачный сервис

Сервис-пример обещает «загрузку до 4K 120 FPS» и пишет, что переписывает MP4-контейнер и метаданные без перекодирования кадров. Пайплайн у него простой: загрузил MP4/MOV → «Optimize» → скачал файл → залил в TikTok через веб с включённым «Upload HD», ничего не редактируя внутри TikTok.

Важно. Сервис нигде не показывает, что именно он меняет в файле, и доказательств эффекта нет. Поэтому мы делаем оба режима: «Ремукс» (как у них, без перекодирования) и «NVENC» (честное перекодирование под рекомендованные параметры TikTok). Какой реально даёт лучший результат после загрузки, проверим A/B-тестом в фазе 4, а не будем верить маркетингу.

Чего у нас не будет: раздачи «Premiere / After Effects / Topaz в комплекте» (это пиратство) и функций для обхода модерации или проверки дубликатов.

Режимы обработки

Что приложение делает с файлом

Ремукс (без перекодирования)

Кадры не трогаем, работает за секунды даже без GPU.

  • moov-атом в начало файла (-movflags +faststart)
  • Правильные цветовые теги: BT.709, limited range
  • Нормализация таймстемпов и fps-метаданных (VFR → CFR-флаги)
  • Удаление мусорных метаданных и лишних дорожек
  • Подходит, если исходник уже H.264/HEVC 8-bit

NVENC (перекодирование на RTX)

Для исходников из монтажек: ProRes, 10-bit, огромный битрейт.

  • h264_nvenc / hevc_nvenc, preset p7, tune hq, 2-pass
  • VBR 10–40 Мбит/с, yuv420p 8-bit, GOP 2 с
  • Масштаб на GPU (scale_cuda), вертикаль 1080×1920
  • Аудио AAC 48 кГц 320 кбит/с
  • Опционально: апскейл RTX VSR (фаза 5)

Технологии

СлойВыборПочему
ОболочкаTauri 2 (Rust)Установщик ~10 МБ вместо ~150 у Electron, нативный доступ к процессам и файлам
ИнтерфейсReact + TypeScript + ViteБыстро собирать экраны, легко найти разработчиков

Требования: Windows 10/11 x64, GeForce RTX 20xx и новее, драйвер 551+. Без RTX приложение работает в режиме «Ремукс» и предлагает CPU-кодирование (libx264) как запасной путь.

Этапы

План работ

Фаза 0

Каркас репозитория

  • Tauri 2 + React шаблон, линтеры, README
  • Скрипт загрузки ffmpeg с NVENC, проверка хэша
  • CI: сборка и тесты на каждый PR
Фаза 1

Анализ и ремукс

  • Определение GPU через NVML, плашка в заголовке
  • ffprobe → карточка файла с предупреждениями
  • Режим «Ремукс» целиком, сохранение рядом с исходником
Фаза 2

NVENC-пайплайн

  • Пресеты в TOML, генератор команд ffmpeg
  • Прогресс, fps, скорость, отмена задачи
  • Очередь из нескольких файлов, лимит параллельных NVENC-сессий
Фаза 3

Интерфейс как в макете

  • Drag-and-drop, слайдер «до/после» по реальным кадрам
  • История, редактор пресетов, настройки папок
  • Русский и английский язык
Фаза 4

A/B-тест на реальных загрузках

  • Один ролик в 4 вариантах: исходник, ремукс, NVENC H.264, NVENC HEVC
  • Скачиваем то, что отдаёт TikTok, сравниваем битрейт, разрешение и VMAF
  • По итогам выбираем пресеты по умолчанию
Фаза 5

Релиз и расширения

  • Установщик, автообновление через GitHub Releases
  • RTX Video Super Resolution для апскейла 720p → 1080p/4K
  • Подписание бинарника, чтобы Windows не ругался
